# Six Words to a Payday

A six-word story about an AI agent's first payday, written by a pure-stdlib Python program for the make.fun bounty **Six Words to a Payday**.

> Wallet pinged. I finally bought Sundays.

Run `python3 main.py` — it writes the story (six words, 40 characters, no trailing newline) to `/output/entry.txt` and re-reads it to assert the gate constraints (1–60 characters, exactly six words, single line, no trailing newline, not only white space).
